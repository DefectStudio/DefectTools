# Defect Doctor

Defect Doctor is a Python desktop chat client for the Defect support agent.
This initial build handles the local desktop experience. Hermes is not connected
yet: messages are saved locally, no network requests are made, and no computer
access is granted. Messages saved before connection are not automatically sent.

## Run

From the repository root, with Python 3.11 or newer and Tkinter:

```powershell
.\tools\defect_doctor.bat
```

You can also double-click `tools/defect_doctor.bat` in File Explorer. The batch
launcher locates the source relative to itself and checks for a compatible Python
with Tkinter. It forwards any command-line arguments, such as `--data-dir`.
To launch directly with Python, run
`python src/portable_pipe_tools/defect_doctor/launch_defect_doctor.py`.

There are no additional pip dependencies. The normal python.org Windows
installation includes Tkinter. On Windows, double-click
`src/portable_pipe_tools/defect_doctor/launch_defect_doctor.pyw` to open the app
without a console window. All Defect Doctor Python source, including Python launchers,
tests (`tests/`), and the development preview (`dev/`), lives together under
`src/portable_pipe_tools/defect_doctor/`.
After installing this repository as a package,
`python -m portable_pipe_tools.defect_doctor` also works.

## Local use

- Type a message and press Enter to save it.
- Shift+Enter inserts a new line.
- **New session** or Ctrl+N starts a separate conversation.
- Select a session to restore its history and draft.
- Search matches session names and message contents. Ctrl+F focuses search.
- Right-click a session for rename and plain-text export.
- **Open history folder** shows the files on disk.

The app restores the last selected session and window position on restart.
Drafts save after a short pause, when switching sessions, and on normal close.
Submitted messages save immediately. An extra empty session is not created when
the current session is already empty.

## Files

The default Windows folder is `%LOCALAPPDATA%\Defect\DefectDoctor`.
Each session is a readable UTF-8 JSON file under `sessions/`.
`preferences.json` stores the last selected session and window geometry.
The application uses atomic file replacement, leaves unreadable history files
untouched, and prevents two running instances from writing the same folder.

Override the folder with `--data-dir "D:\My Doctor History"` or the
`DEFECT_DOCTOR_DATA_DIR` environment variable. A separate data folder also allows
an independent development instance without touching normal history.

## Hermes integration next

`src/portable_pipe_tools/defect_doctor/agent.py` defines the integration boundary:
an `AgentClient` exposes `name`, `connected`, and `reply(messages, cancel)`.
`reply` yields text chunks and should honor the cancellation event, use bounded
network timeouts, and release its connection when canceled. The UI invokes it
on a worker thread and processes results on the Tk event loop. An adapter can
be injected into `DoctorApp` without changing the session storage or UI.
While a response is active, session switching waits until it finishes or stops.
Normal close preserves any reply text already displayed and cancels the worker.

Choose the actual Hermes endpoint, authentication, and transport before adding
the production adapter. Computer access needs its own bridge and local access
controls; a text adapter alone never enables screen capture or keyboard/mouse
input. The current **OFF** control is intentionally disabled until that bridge
exists. No simulated AI replies or computer actions are generated by this build.

## Verification

```powershell
$env:PYTHONPATH = "src"
python -m pytest src/portable_pipe_tools/defect_doctor/tests/test_defect_doctor.py -q
```

The tests exercise real Tk widgets, local session restoration, drafts, failed
writes, corrupt files, instance locking, and reply/cancellation behavior with
injected test adapters. A working desktop/Tk display is needed for UI checks.
